
# DevSecOps CI/CD Security Lab

## Project Overview
This project is a simple Flask web application created for a hands-on DevSecOps security assignment.

It demonstrates how security scanning tools can identify potential vulnerabilities in application code, dependencies, infrastructure configuration, and container configuration.

## Technologies Used
- Python 3.11
- Flask
- GitHub Actions
- Docker
- Terraform

## Project Files
- `app.py` - Flask web application
- `requirements.txt` - Python dependencies
- `config.py` - Dummy credentials for security testing
- `Dockerfile` - Container configuration
- `main.tf` - Terraform configuration
- `.gitignore` - Files excluded from Git

## Security Testing
The project contains intentionally insecure examples for educational security scanning in an isolated test environment.

Do not deploy the application or Terraform configuration to production.

## Disclaimer
All credentials used for testing are dummy values. No real secrets or personal data should be committed to this repository.
